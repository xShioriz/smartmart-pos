# สคริปต์สาธิต (ประมาณ 10–12 นาที)

เว็บหลัก: https://smartmart-pos-sage.vercel.app/ · ข้อมูลสาธิตมีบิลย้อนหลัง 30 วัน
ล็อกอิน: admin / cashier (รหัสผ่านที่ตั้งไว้ตอน seed — **ห้ามใส่ในเอกสารนี้ ให้จดแยกไว้ส่วนตัว**)

## ก่อนเข้าห้อง (15 นาทีก่อน)
- [ ] เปิดเว็บ production ล็อกอิน admin ในหน้าต่างหนึ่ง และ cashier ในหน้าต่างไม่ระบุตัวตน (Incognito) อีกหน้าต่าง
- [ ] เปิดแท็บ Omise test dashboard (โหมด Test) ค้างไว้
- [ ] เปิดแท็บสำรอง `npm run build && npm start` ในเครื่อง (ชี้ฐาน dev) ทดสอบล็อกอินได้
- [ ] ปิดกะที่ค้างอยู่ (ถ้ามี) เพื่อให้ตอนสาธิตเปิดกะใหม่ได้
- [ ] จดอีเมล/รหัสผ่านแอดมิน-แคชเชียร์ไว้ในที่ที่ไม่ได้ฉายบนจอ
- [ ] แคปภาพหน้าจอทุกหน้าหลักเก็บไว้ในโฟลเดอร์เดียว (แผนสำรองข้อ 4)
- [ ] ต่อเน็ตสำรอง (ฮอตสปอตมือถือ)

## ลำดับการสาธิต

### 1) ภาพรวม (1 นาที) — หน้า Dashboard (admin)
พูด: ร้านสะดวกซื้อขนาดเล็ก ใช้ POS นี้ขาย จัดสต็อกแบบล็อต ดูรายงาน
ชี้: ยอดขายวันนี้ กราฟยอดขายและจำนวนบิลรายวัน สินค้าขายดี การ์ด Smart BI; ลองเลือกช่วงวันที่เองที่การ์ดกราฟ
ย้ำ: Smart BI ใช้กฎ/สถิติ ไม่ใช่ AI และกดดูวิธีคำนวณได้ทุกข้อ

### 2) ขายเงินสด (2 นาที) — แคชเชียร์
1. ล็อกอิน cashier → POS → สแกน/ค้นหาสินค้า 2–3 ชิ้น
2. แสดงส่วนลดโปรโมชันอัตโนมัติ (เลือกสินค้าที่เข้าโปรอยู่จริง — ตรวจหน้า "โปรโมชัน" ก่อนว่ามีโปรที่ยังไม่หมดอายุ)
3. ใส่สมาชิก (ค้นด้วยเบอร์) → จ่ายเงินสดด้วยแป้นตัวเลขบนจอ → ทอนเงิน → ใบเสร็จ
พูด: ราคา ส่วนลด สต็อก คำนวณที่ server ทั้งหมด ไม่เชื่อค่าจากหน้าเว็บ; กดจ่ายซ้ำไม่เกิดบิลซ้ำ

### 3) ขาย PromptPay QR (2 นาที)
1. สร้างบิล เลือก PromptPay → แสดง QR (Sandbox)
2. สลับไป Omise test dashboard → Mark as paid
3. กลับหน้า POS → บิลเปลี่ยนเป็นชำระแล้วเอง
พูด: ระบบยืนยันโดยเรียก API ผู้ให้บริการเอง ไม่เชื่อ webhook อย่างเดียว; โหมด Sandbox ไม่มีเงินจริง

### 4) สต็อก (1.5 นาที) — คลังสินค้า
- เปิดหน้าคลังสินค้า: กดหัวตาราง **สถานะ** และ **หมดอายุถัดไป** เพื่อโชว์การเรียง
- กดปุ่ม **รายการที่ควรสั่งซื้อ** (admin) ให้เห็นสินค้าที่ต้องสั่งพร้อมจำนวนแนะนำและประมาณการมูลค่า แล้วดาวน์โหลด CSV
- เข้าสินค้าหนึ่งชิ้น → ดูรายล็อต วันหมดอายุ
- เปิดแท็บ "ประวัติเคลื่อนไหว" ดูรายการ "ขาย" ที่เพิ่งเกิด ว่าตัดจากล็อตไหน (ระบบตัดล็อตที่หมดอายุก่อน = FEFO) — **ซ้อมดูหน้านี้ก่อน** เพื่อให้แน่ใจว่าแสดงเลขล็อตตามที่จะพูด

### 5) คืนสินค้า (1 นาที) — admin
ประวัติการขาย → เปิดบิลที่เพิ่งขาย → คืนสินค้า 1 รายการ → สต็อกกลับล็อตเดิม แต้มสมาชิกถูกกลับรายการ

### 6) รายงานและ CSV (1 นาที)
รายงาน → เลือกช่วงวัน → ดาวน์โหลด CSV → เปิดใน Excel (ภาษาไทยไม่เพี้ยน)

### 7) ปิดกะ (1 นาที)
เปิดกะด้วยเงินตั้งต้น → ปิดกะ ใส่เงินที่นับได้ → ระบบแสดงยอดที่ควรมีและส่วนต่าง (ถ้าต่างต้องใส่หมายเหตุ)

### 8) ความปลอดภัย (1 นาที — พูดสั้น ๆ)
- สิทธิ์ 2 ระดับบังคับฝั่ง server; cashier พิมพ์ URL หน้าแอดมินแล้วเข้าไม่ได้ (ลองให้ดูได้)
- ล็อกอินผิดซ้ำถูกล็อกชั่วคราว; Audit log บันทึกการกระทำสำคัญ

### 9) มือถือ/iPad (30 วินาที, ถ้ามีเครื่อง)
เปิดบนมือถือ: เมนูลิ้นชัก ตะกร้าเต็มจอ แป้นตัวเลข

## คำถามที่น่าจะโดน — คำตอบสั้น
| คำถาม | ตอบ |
|---|---|
| ทำไมไม่ใช้ AI ใน Smart BI | ต้องอธิบายผลได้และตรวจสอบได้; ใช้ถดถอยเชิงเส้นของยอดขาย 7 วัน (แนวโน้ม) และกฎ เช่น วันที่สต็อกพอขาย = สต็อก ÷ ยอดขายเฉลี่ย/วัน แล้วแสดงสูตรกำกับทุกข้อ |
| รับเงินจริงได้ไหม | ยังไม่ได้ ใช้ Sandbox; ต้องสมัคร merchant กับผู้ให้บริการและเปลี่ยน key + `PAYMENT_ENV` |
| สต็อกถูกต้องได้อย่างไร | แหล่งความจริงอยู่ที่ล็อต; แก้ผ่าน service เดียว; มีสคริปต์ตรวจ drift (`check-deploy`) |
| ถ้าเน็ตล่มระหว่างจ่าย QR | บิลค้างสถานะรอชำระ ไม่ตัดสต็อก; มี reconcile ตรวจกับผู้ให้บริการภายหลัง |
| ผู้ใช้พร้อมกันเยอะไหม | ยังไม่ได้ทดสอบโหลด; ออกแบบให้ stateless บน serverless + transaction/lock ที่จุดสำคัญ |
| ทดสอบอะไรไปบ้าง | ดู `TEST_SUMMARY.md` (196 เคส + ตรวจสิทธิ์ผ่าน HTTP 151 ข้อ + ทดสอบมือบน production) |

## แผนสำรองถ้าอะไรพัง
1. **เว็บ production ล่ม/ช้า** → สลับไปเครื่องตัวเอง `npm start` (ชี้ฐาน dev)
2. **เน็ตล่ม** → เครื่องตัวเองยังรันได้ถ้าฐาน dev เข้าถึงได้; ถ้าไม่ได้เลย สาธิตจากภาพหน้าจอที่เตรียมไว้ + ชี้ผลทดสอบ
3. **QR ไม่ขึ้น/Omise มีปัญหา** → ข้ามไปสาธิตเงินสดอย่างเดียว บอกว่า QR ทำงานผ่านการยืนยันจาก API
4. **ล็อกอินไม่ได้ (โดนล็อก)** → รอ 15 นาที หรือใช้ผู้ใช้อีกคน/เครื่องสำรอง
5. **ข้อมูลสาธิตเพี้ยน** → ห้ามรัน seed ซ้ำบนฐานเดิม (ไม่ idempotent); สร้าง Neon branch ใหม่จากสำเนาที่สะอาด
